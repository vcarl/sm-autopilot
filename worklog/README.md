# Worklog

One file per finished task, named `YYYY-MM-DD-HHMMSS-<task-slug>.md`, written by
`scripts/codex_workflow.py` when a task is accepted, blocked, or left unfinished.
Nothing here is written by hand and nothing here is edited after the fact.

Each entry is built from the run's artifacts, not from prose: the accepted plan's
task, acceptance, and scope; the files that changed; every fixed check with its
exit code; the independent review's verdict, findings, and evidence; and the
worker's own findings quoted under a heading that says they are a claim.

Readers take the two newest entries by name. Older entries are reached only when
a task cites one. The index is `ls`.
