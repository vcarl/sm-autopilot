# Image spikes

The explorations behind the pilot pictures, in order. Each gives the question, the method, the findings, the verdict, and
what was kept or dropped. The scripts, prompts and renders were never committed; they live in untracked `experiments/`
directories on the maintainer's machine. The lessons that outlive them are in the
[pilot pictures design](../specs/2026-10-16-pilot-pictures-design.md#what-the-image-spikes-taught-us).

1. [Map](01-map.md): a faithful activity map from the journal alone; the activity map's reference.
2. [Moment scorer](02-moments.md): the event catalogue and seven dry runs; score from the raw frame log.
3. [References](03-references.md): edit mode, cropped art, camera first, a part-based pose, 2–3 seeds.
4. [Pasted stickers](04-stickers.md): rewording the reference sentence unpastes nothing.
5. [The game's words](05-catalog-words.md): raw and extracted text add nothing; a sun by its class is the best word.
6. [Two passes](06-two-pass.md): cockpit plates composited with the view worked, and were shelved.
7. [Chroma key](07-chroma-key.md): a prompted magenta screen is the better matte, for the shelved pipeline.
8. [The loose prompt](08-loose.md): one pass, no style frame, the cockpit in words.
9. [Cameras and clothing](09-cameras.md): three cameras by seed; clothing ends the airline-captain drift.
