# SpaceMolt checklist

## Using this checklist

- This is the checklist. [VISION.md](VISION.md) is intent; `worklog/` is history, one file per finished task, written by `scripts/codex_workflow.py` from verified artifacts. Neither is edited from here.
- Check an item only when its observable result exists. A stub, an accepted command, or a model claim is not completion.
- Put evidence beside a checked item: path, test command, or reviewed receipt. Name the level (fixture, replay, live).
- Record progress, decisions, and the next action here before ending work.
- Reopen an item when later evidence invalidates it.
- IDs are local to this file. The vision has none; do not invent cross-references to it.
- Work runs through `scripts/codex_workflow.py` (see `scripts/codex_workflow.md`): the operator names one milestone, usually one item or a few adjacent items from this file, and the fixed checks; while the tree is deliberately broken, checks are task-scoped (`node --test <file>`) or a checked-in script, never the whole suite.

## Decisions (D)

- [ ] D1 — Stop authority: only the operator's stop overrides the agent. A script may refuse a job or suspend one, never redirect the pilot. Written down with permitted and rejected examples.
- [x] D2 — Mood resolves to numbers: each word maps to reserves, pursuit, spend, and walk-away margins in one table. Nothing is passed per call. Decided 2026-09-14 (controller session; numbers are a technical default, revisable with evidence). The table below is authoritative until R7 encodes it in code, after which the code is; scripts read it, the agent never passes margins.
  - Columns: fuel reserve (units, kept in the tank beyond the quoted route, checked before departure and again before the return leg) / hull retreat fraction (walk away from a fight below this) / gather cycles / route jumps / max liability (credits) / max spend per job (credits). Tank is 120 units and hull 55-105 on observed ships (`spacemolt/evidence/*.json`), so reserves are units, not fractions.
  - Relaxed 30 / .90 / 2 / 1 / 500 / 500. Cautious 30 / .95 / 2 / 1 / 500 / 500. Focused 24 / .90 / 4 / 2 / 1000 / 1000. Opportunistic 20 / .90 / 4 / 2 / 1000 / 1000. Aggressive 12 / .80 / 6 / 2 / 2000 / 2000. Tired 0 / .95 / 0 / 0 / 0 / service only (the reserve is 0 because Tired's one trip is the resupply leg itself).
  - Relaxed and Tired may not initiate a job. Operator overrides tighten only (R7 mined rule). Credit reserve floor 150000 is a permission, not a mood value (D11).
- [x] D3 — Tired margins: which resources cross (fuel, hull, ammunition, credits), per mood, and what resupply must restore to clear it. Decided 2026-09-14 (controller session), same caveat as D2.
  - Crossing (any one imposes Tired, evaluated from a live read at every checkpoint): fuel < quoted route to the nearest serviced station + the mood's fuel reserve (D2); hull < the mood's retreat fraction of max hull while not in combat (in combat the same number is the retreat trigger, R15); ammunition: a fitted magazine weapon with no full reload left in cargo (non-magazine fits never cross); credits: wallet < 2x (full refuel + full repair) at the current or nearest serviced station's posted prices (data-driven, no fixed number, identical for every mood).
  - Resupply clears Tired when every crossed resource is back above its line: fuel to full tank when docked with service, else to route-to-home + reserve; hull to full when docked with service, else above the retreat fraction; ammunition to one loaded magazine plus one reload; credits above the 2x line (via sale, deposit withdrawal, or contract payout, R13). Clearing restores the mood held before the crossing (R8); the prior mood is journaled at the crossing, never latched anywhere else.
  - Resupply is a pit stop at any serviced station, not rest; Tired at home does not end the shift.
